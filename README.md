# Proyecto_PACD

Actividad final de **Programación Avanzada para Ciencias de Datos**: proyecto reproducible sobre el balance hídrico en estaciones agroclimáticas de INIA (2016–2025).

**Docente:** Marcelo Danessi

**Autores:** Alejandra Ramírez, Alvaro Barreto, Katerin Gonzalez y Gabriela Flores.

## Contenido

- [`proyecto_inia/`](proyecto_inia/): el proyecto completo (datos, código, resultados e informe Quarto). Ver su [README](proyecto_inia/README.md) para la estructura y cómo ejecutarlo.
- [`presentacion/`](presentacion/): material de apoyo para la presentación (PDF).

## Ejecución rápida

```
cd proyecto_inia
Rscript run_all.R
```

Genera todo desde los datos originales y produce `proyecto_inia/report/informe.html`.
